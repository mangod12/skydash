# SkyDash Brand System

## Positioning

SkyDash is a spatial intelligence OS for teams that need to turn live telemetry,
entity context, map layers, and mission notes into analyst-ready decisions.

## Core Brand

- Name: SkyDash
- Wordmark: SKYDASH
- Short mark: SD
- Category: Spatial Intelligence OS
- Tagline: Command the signal. Map the risk.
- Descriptor: Local-first spatial intelligence for drone telemetry, entity graphs, and mission context.

## Brand Pillars

- Live: real-time telemetry, WebSocket status, and current operating context.
- Spatial: maps, coordinates, geofences, relationships, and movement history.
- Analytical: entity graphs, timelines, exports, and CrewAI-generated briefs.
- Local-first: inspectable, hackable, and clear about prototype boundaries.

## Voice

SkyDash should sound operational, precise, and calm. Use short nouns and verbs:
track, map, brief, verify, correlate, dispatch, export, monitor.

Avoid inflated claims such as autonomous defense, guaranteed detection, or
production-ready intelligence. When the stack is simulated or local-only, say so.

## Visual System

- Base: zinc/near-black surfaces for focused operations.
- Primary brand: indigo `#6366f1`.
- Telemetry/data: cyan `#22d3ee`.
- Healthy/connected: emerald `#10b981`.
- Warning: amber `#f59e0b`.
- Critical/threat: red `#ef4444`.
- Intelligence: violet `#8b5cf6`.
- Spatial/navigation: blue `#3b82f6`.

Color is semantic. Do not use red, amber, emerald, or cyan decoratively when they
could be read as status.

## Product Naming

- Platform: SkyDash
- App category: SkyDash Spatial Intelligence OS
- API: SkyDash Spatial Intelligence API
- CrewAI runner: SkyDash Intel Crew
- Reports: SkyDash Intelligence Brief

## Usage Rules

- Use `SkyDash` in prose.
- Use `SKYDASH` only for wordmarks, boot text, console headers, and compact UI chrome.
- Use `SD` only where space is constrained.
- Keep screenshots and demos showing real UI surfaces, not marketing placeholders.
